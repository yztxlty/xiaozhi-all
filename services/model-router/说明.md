# 模型路由器

> 状态：开发中<br>
> 版本：v0.1<br>
> 更新日期：2026-08-28

## 当前能力

- 统一 `LLMRequest` 和流式事件契约。
- 通过 `POST /v1/chat-messages` 调用无状态 Dify Chatflow。
- 每轮传入角色、短期上下文和长期记忆，`conversation_id` 固定为空。
- 使用 `httpx.AsyncClient.stream()` 实时读取 `message`、`agent_message` 和 `message_end`。
- 首个文本增量前最多重试一次；产生文本后不重试、不拼接备用回复。
- 支持本地取消、Dify Stop API 和迟到事件隔离。

## 本地调用

```bash
export DIFY_CHATFLOW_BASE_URL='https://你的服务地址/v1'
export DIFY_CHATFLOW_API_KEY='你的 Chatflow 应用密钥'

.venv/bin/xiaozhi-dify '今天有点累' \
  --用户标识 '本地验收用户' \
  --角色 '{"name":"幽光","persona":"温暖、自然、不过度说教"}'
```

真实密钥只允许由环境变量或密钥管理系统注入，禁止写入仓库、日志和测试数据。
