# 模型提供方契约

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

## 公共要求

每个模型提供方必须声明能力、地区、格式、超时、取消、限流和计费单位；不得在业务代码中通过供应商名称分支调用软件开发工具包。

## 能力描述

```json
{
  "provider": "provider-name",
  "kind": "asr|llm|tts",
  "streaming_input": true,
  "streaming_output": true,
  "cancel_supported": true,
  "formats": ["pcm_s16le_16k_mono", "opus_16k_mono"],
  "regions": ["cn"],
  "timeout_ms": 3000
}
```

## 语音识别契约

- 输入：有序音频帧流。
- 输出：临时识别结果、最终识别结果、置信度、词或词元时间戳。
- 必须支持结束输入、取消和超时。
- 失败后只有在没有提交最终识别结果时才允许切换备用模型提供方。

## 大语言模型契约

- 输入：结构化角色、历史、用户文本、工具和生成任务上下文。
- 输出：有序词元或文本增量、用量、结束原因和工具调用。
- 必须支持取消；重试使用新生成任务，不能把两次输出拼接。
- Dify 工作流模型提供方的无状态输入、服务端事件流事件、错误和取消扩展见 [Dify 工作流模型提供方契约](Dify工作流提供方契约.md)。

## 语音合成契约

- 输入：可追加文本片段、音色、情感、采样率和生成任务。
- 输出：有序音频块、字幕时间戳、用量和完成事件。
- 必须支持持久会话、取消或明确声明不支持。
- 不支持取消的模型提供方不能作为可打断主链路。

## 路由和降级

路由器按场景、质量、延迟、成本、地区和健康状态选择模型提供方。切换必须产生观测事件，并记录原模型提供方、目标模型提供方、原因、额外延迟和额外成本。
