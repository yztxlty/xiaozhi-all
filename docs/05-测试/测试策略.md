# 测试策略

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

## 测试层级

- 单元测试：状态机、分句、路由、计费、超时、序号和幂等。
- 契约测试：设备协议、模型提供方、数据库和客户端 SDK。
- 集成测试：Gateway、语音运行时、语音识别、大语言模型、语音合成完整事件流。
- 故障测试：超时、断线、乱序、丢包、重复、迟到帧、模型提供方切换。
- 性能测试：阶段延迟、并发、CPU、内存、带宽和成本。
- 真机测试：AEC、起播、打断、弱网、重连、长稳和温升。

## 音频测试集

测试集至少覆盖普通话男女声、儿童和老人音高、近场和远场、快慢语速、短句和长句、停顿、附和、咳嗽、电视背景声、音乐、设备自播回声和网络抖动。音频必须获得授权并脱敏。

## 统计规则

- 每组性能测试至少包含 100 个有效轮次。
- 同时报告 P50、P95、P99、均值、错误率和样本数。
- 冷启动和热连接分别统计。
- 模型提供方、地区、设备固件、网络和服务提交必须固定并记录。
- 不允许删除失败样本；无效样本必须说明排除原因。
