# 测试与验收基线

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

## 实时体验

| 项目 | 通过标准 |
| --- | --- |
| 语音识别首个 partial | P95 ≤ 250ms |
| 用户停止到语音识别最终结果 | P95 ≤ 350ms |
| 大语言模型首字延迟 | P95 ≤ 450ms |
| 语音合成首包 | P95 ≤ 300ms |
| 用户结束到设备首音 | P50 ≤ 900ms，P95 ≤ 1.2s |
| 打断到停止播放 | P50 ≤ 120ms，P95 ≤ 250ms |
| 误打断恢复 | 有效恢复率 ≥ 95% |

## 必测场景

1. 正常连续对话 20 轮。
2. AI 播放开头、中间、结尾分别打断。
3. 咳嗽、清嗓、短促“嗯”不应错误丢弃回复。
4. 5%、10% 丢包和 100/300/800ms 抖动。
5. Wi-Fi 短断后重连，旧生成任务音频不得播放。
6.语音识别、大语言模型、语音合成分别超时和主备切换。
7. 连续 30 分钟，检查堆、PSRAM、任务数、队列和连接数。
8. 设备播放音频时继续采集，验证 AEC 和真实打断。

## 发布阻断条件

- 任一 P0 指标不达标。
- 出现旧音频串入、重复计费、历史提交未听内容或密钥泄露。
- 真机未执行，只通过模拟器或单元测试。
- 测试结果缺少版本、环境、样本和原始证据。
