# 幽光陪伴式 H5 语音通话实施计划

> **执行要求：** 按任务顺序逐项执行，每项均遵循测试先失败、最小实现、测试转绿、相关回归的循环。

**目标：** 把现有 H5 工程测试页升级为可连续语音对话、可真实打断、可查看响应时延和实时调试日志的幽光陪伴产品 Demo。

**架构：** 保留现有 WebSocket、PCM、阿里云 DashScope Paraformer Realtime v2、阿里云通义千问 Qwen 3.7 Flash、火山引擎 BigTTS v3 全链路。H5 按页面结构、视觉样式、通话状态与音频控制拆分；连续对话复用成熟 Silero VAD 浏览器实现，失败时回退到按住说话。

**技术栈：** 原生 HTML/CSS/JavaScript、Web Audio API、WebSocket、`@ricky0123/vad-web 0.0.30`、ONNX Runtime Web 1.22.0、Python `pytest`、Node.js 内置测试。

## 全局约束

- 不替换 ASR、大模型和 TTS Provider；低延迟只调整实时编排参数和校正语义。
- 不引入前端框架或构建工具。
- 页面文案使用中文，模型链路按“厂商 + 产品/模型 + 版本 + 阶段”展示。
- 调试日志必须脱敏，默认收起，移动端和桌面端均不得遮挡核心操作。
- 打断后必须立即停止本地播放，并丢弃旧一轮在途音频直至 `tts.done`。
- 手机端优先，HTTPS 麦克风权限异常必须给出可操作提示。
- 真实浏览器中从用户说完到收到首段 TTS PCM 必须低于 `1000ms`。
