# 幽光状态动图与情绪协议实施计划

> **给执行代理：**按任务逐项执行，每项必须先红后绿；完成后运行总回归。不得改动已通过的拾音、TTS、WebSocket 音频核心逻辑。

**目标：**将 H5 通话页的 CSS 角色替换为统一高清毛绒动图，并让实时阶段与大模型情绪标签驱动角色表现。

**架构：**服务端只输出标准 `assistant.emotion` 事件；前端由独立角色状态控制器把实时阶段和情绪标签映射到唯一资源。动图资源固定 `280×280`、透明背景和统一锚点，加载失败回退静态首帧，不阻塞语音链路。

**技术栈：**原生 JavaScript、CSS、APNG/透明 PNG、Python `websockets`、现有 Pipecat 运行时、现有 pytest 与 Node 测试。

## 全局约束

- 所有状态只允许 `idle`、`listening`、`hearing`、`recognizing`、`thinking`、`speaking`、`happy`、`sad`、`comforting`、`surprised`、`error`。
- 情绪只允许 `neutral`、`happy`、`sad`、`comforting`、`surprised`；未知值回退 `neutral`。
- 阶段状态优先于情绪状态；TTS 结束后才展示情绪动图，并在短暂展示后回到聆听或待机。
- 动图资源必须透明、固定 `280×280`、无白底/绿底/棋盘格/毛边/黑边/漂移/杂点。
- 不得在浏览器端重新实现 ASR、TTS、VAD 或模型逻辑。
- 不得删除或替换现有语音协议、录音、播放和打断代码。
- 情绪协议、情绪适配、状态决策、资源清单、H5 渲染必须是独立边界；任何一层不得直接依赖具体模型、WebSocket、DOM 或音频实现。
- 资源渲染必须通过适配器隔离，采用“透明高清底图 + 透明表情动画层”减少存储；后续可平滑替换为 App、LVGL、精灵图或 PNG 序列，不修改上层状态决策。

import assert from 'node:assert/strict';
import { getMascotAsset, MASCOT_ASSETS } from '../mascot-assets.js';

test('所有角色状态都有唯一资源并统一规格', () => {
  const states = ['idle','listening','hearing','recognizing','thinking','speaking','happy','sad','comforting','surprised','error'];
  for (const state of states) {
    const asset = getMascotAsset(state);
    assert.match(asset.src, /^\.\/assets\/mascot\/.+\.(apng|png)$/);

  assert.notEqual(MASCOT_ASSETS.happy.src, MASCOT_ASSETS.sad.src);
});

test('未知状态安全回退待机资源', () => {
  assert.deepEqual(getMascotAsset('unknown'), getMascotAsset('idle'));
});
