# DeepSeek 临时模型接入实施计划

> **执行要求：** 按任务顺序进行 TDD 红绿循环，完成真实全链路验证后才可交付。

**目标：** 新增通用 OpenAI 兼容 Provider，临时将实时语音链路切换到 DeepSeek，同时保留 Dify 一键回切能力。

**架构：** Provider 协议实现位于 `model-router`；`realtime-server` 仅在组合根选择 Provider；现有异步 TTS 队列、ASR 和 WebSocket 协议保持不变。

**技术栈：** Python 3.12、`httpx`、Pydantic、SSE、pytest、WebSocket、PCM 16kHz。

## 全局约束

- 不新增 OpenAI SDK。
- 默认使用 `deepseek-v4-flash` 并关闭思考模式。
- 密钥只保存到被忽略的 `.env`。
- Dify Provider 不删除、不改协议。
- 所有文档使用中文目录、中文文件名和中文正文。
