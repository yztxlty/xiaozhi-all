# 发布、版本与回滚规范

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

## 版本

- 服务和客户端使用语义化版本 `MAJOR.MINOR.PATCH`。
- 实时协议独立维护主版本；破坏兼容必须升级主版本。
- 设备固件记录协议版本、资源版本、分区版本和构建提交。

## 发布门禁

发布包必须具备：变更清单、依赖清单、数据库和配置迁移、协议兼容说明、自动化与真机报告、容量结果、监控面板、告警、回滚步骤和负责人。

## 灰度

按内部设备、测试用户、1%、10%、50%、100% 分阶段放量。每阶段观察首音、打断、错误率、重连、模型提供方成本和设备崩溃；超过基线阈值立即停止放量。

## 回滚

- 服务端必须能够回滚到上一稳定镜像。
- 协议保持前一主版本兼容，禁止要求设备同步瞬时升级。
- 数据迁移优先向前兼容；不可逆迁移必须先备份并演练恢复。
- 固件 OTA 必须保留安全回滚或恢复路径，未经真机验证不得量产发布。
