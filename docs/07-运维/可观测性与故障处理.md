# 可观测性与故障处理

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

## 每轮必采指标

- 会话 建连、重连和断开原因。
- VAD 开始/结束、Smart轮次 耗时和误打断。
- 语音识别首 partial、final、置信度和识别秒数。
- 大语言模型首字延迟、完成时间、词元、取消和工具调用。
- 语音合成首包、完成时间、字符数、取消和音频秒数。
- 终端首音、缓冲深度、丢包、`played_ms` 和停止播放时间。
- 模型提供方错误率、熔断、降级、调用量和成本。

## 关联

日志、Trace 和指标统一携带 `session_id`、`turn_id`、`generation_id`、匿名设备标识、终端类型、协议版本和 Provider；不得记录完整用户音频、密钥和未经脱敏的长期文本。

## 服务等级目标起点

- 会话建立成功率 ≥ 99.9%。
- 有效轮次 成功率 ≥ 99.5%。
- 首音 P95 ≤ 1.2 秒。
- 打断停止 P95 ≤ 250 毫秒。

## 事件等级

- P0：大面积不可用、密钥或用户数据泄露、设备升级导致批量不可恢复。
- P1：核心语音质量显著下降、首音或打断持续超标、单一地区不可用。
- P2：非核心功能故障或存在可靠降级。

P0/P1 先止损和回滚，再定位；24 小时内形成时间线，72 小时内完成无责复盘、根因、检测缺口和防复发任务。
