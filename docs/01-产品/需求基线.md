# 需求基线

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

## P0 功能需求

| 编号 | 需求 | 验收摘要 |
| --- | --- | --- |
| FR-001 | 终端持续上传音频帧 | 服务端可边接收边识别，不等待整段文件 |
| FR-002 | 流式语音识别 | 支持 partial、final、置信度和时间戳 |
| FR-003 | 流式大语言模型 | 首批稳定词元可直接进入语音合成 |
| FR-004 | 流式语音合成 | 不生成临时 MP3，不依赖 TOS 才能首播 |
| FR-005 | 用户打断 | 可取消旧大语言模型、语音合成、下行队列和终端播放 |
| FR-006 | 误打断恢复 | 无有效转写时可从已确认播放位置恢复 |
| FR-007 | 模型提供方切换 | 语音识别、大语言模型、语音合成可独立配置主用、备用和超时 |
| FR-008 | 多终端接入 | ESP32、未来芯片、网页端、移动端 共用会话运行时 |
| FR-009 | 播放确认 | 终端上报 `played_ms`，历史只提交已听内容 |
| FR-010 | 故障降级 | 单一模型提供方故障不导致会话进程失控 |

## P0 非功能需求

| 编号 | 指标 | 目标 |
| --- | --- | --- |
| NFR-001 | 用户结束到设备首音 | P50 ≤ 900ms，P95 ≤ 1.2s |
| NFR-002 | 打断到停止播放 | P50 ≤ 120ms，P95 ≤ 250ms |
| NFR-003 | 语音识别最终结果 | 用户停止后 P95 ≤ 350ms |
| NFR-004 | 大语言模型首字延迟 | P95 ≤ 450ms |
| NFR-005 | 语音合成首包 | P95 ≤ 300ms |
| NFR-006 | 长稳 | 连续 30 分钟无崩溃、串音和持续内存增长 |
| NFR-007 | 安全 | 全链路 TLS 校验，终端和客户端不持有云服务密钥 |
| NFR-008 | 可观测 | 每轮可关联 会话、轮次、生成任务和模型提供方指标 |

## P1 需求

- 网页端/移动端 WebRTC 接入。
- 长期记忆、情绪状态和角色一致性。
- 离线歌曲 3 至 5 首、音乐播放与语音会话资源仲裁。
- 设置与小游戏作为独立应用模块，通过统一资源和生命周期管理接入。

## 变更控制

新增或修改 P0 需求必须同步更新架构、协议、测试用例和风险登记；降低性能指标必须形成 架构决策记录，不能直接修改实现规避验收。
