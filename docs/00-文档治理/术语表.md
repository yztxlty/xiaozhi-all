# 术语表

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

| 术语 | 定义 |
| --- | --- |
| 会话 | 一次终端与平台建立并维持的实时连接周期 |
| 轮次 | 用户或 AI 的一轮连续表达 |
| 生成任务 | 同一轮回复的生成代次；重试或重新回答必须递增 |
| 音频帧 | 带序号、时间戳和音频格式的最小传输单元 |
| 临时语音识别结果 | 尚未确认的增量识别结果 |
| 最终语音识别结果 | 当前用户轮次可提交给大语言模型的最终识别结果 |
| 语音活动检测 | 判断音频中是否存在人声，不等同于判断一句话是否结束 |
| 智能轮次 | 结合音频和语义信号判断用户轮次是否结束 |
| 用户打断 | 用户在人工智能回复播放过程中主动说话并打断回复 |
| 误打断 | 咳嗽、噪声或附和导致的错误打断 |
| 首字延迟 | 大语言模型从请求到首个词元的时间 |
| 首音频字节延迟 | 语音合成从收到文本到首个音频字节的时间 |
| 首段音频延迟 | 从用户轮次结束到终端实际开始播放人工智能音频的时间 |
| 控制面 | 账号、角色、配置、记忆、计费和管理能力 |
| 实时数据面 | 音频、转写、生成、取消和播放确认的低延迟链路 |
| 模型提供方 | 语音识别、大语言模型、语音合成或其他模型服务的统一适配实现 |
