# 项目里程碑与风险基线

> 状态：基线生效
> 版本：v0.1
> 更新日期：2026-08-28

## 里程碑

| 里程碑 | 目标 | 核心出口 |
| --- | --- | --- |
| M0 | 基线、协议和测试工具 | 可重复测量全链路阶段延迟 |
| M1 | ESP32 真机闭环 | 首音、打断、长稳全部达标 |
| M2 | 成本与可靠性 | 本地语音识别评测、主备和弱网恢复 |
| M3 | 网页端/移动端 接入 | 多终端复用统一 Runtime |
| M4 | 陪伴与应用生态 | 角色记忆、音乐、设置、小游戏 |

## 初始风险

| 风险 | 等级 | 触发信号 | 处理策略 |
| --- | --- | --- | --- |
| ESP32 AEC 在自播时效果不足 | 高 | 播放时语音识别大量识别到回声 | 设备调参、输出参考、服务端双重判定 |
| 本地语音识别中文噪声场景质量不足 | 高 | CER 超过付费基线或 final 延迟超标 | 付费主用、本地影子、按置信度路由 |
| 语音合成不支持可靠取消 | 高 | 打断后仍计费或迟到音频持续到达 | 只选可取消模型提供方，生成任务丢弃保护 |
| 模型提供方区域网络抖动 | 中 | 首包 P95 持续超标 | 同区域部署、预热连接、主备路由 |
| 协议演进导致旧设备失联 | 高 | 新服务拒绝旧协议 | 双版本兼容、能力协商、分批 OTA |
| 过早拆微服务拖慢 MVP | 中 | 服务数量增长但无独立扩缩容依据 | 模块化单体起步，以压测证据拆分 |

## 变更管理

风险等级、需求范围、P0 指标、协议主版本或核心模型提供方策略变化必须同步更新本文档及关联 架构决策记录；每个里程碑评审一次未关闭风险。
